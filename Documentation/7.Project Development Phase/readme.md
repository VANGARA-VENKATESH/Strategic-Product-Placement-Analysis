
Project Development Phase
1. Data Connectivity

The system establishes seamless data connectivity between the retail dataset and the analytics platform.

Data source connected using structured CSV dataset.

Secure integration between Flask backend and Tableau dashboards.

Real-time data linking enabled.

Data refresh functionality implemented.

Ensured data consistency and integrity during loading.

The connectivity layer ensures smooth data flow without latency or data corruption.

2. Data Preparation

Before visualization, data preprocessing steps were performed to ensure accuracy and reliability.

Removed null and duplicate values.

Standardized date formats and numerical fields.

Applied aggregation functions (SUM, AVG, COUNT).

Created calculated fields (Profit Margin, Sales Growth Rate, Discount Impact).

Data normalization for consistent analysis.

Prepared dataset ensured clean, structured, and analytics-ready information.

3. Dashboard

An interactive analytical dashboard was developed to visualize key business metrics.

Dashboard Features:

Sales Trend Analysis

Product Category Performance

Competitor Price Comparison

Promotion Impact Visualization

Regional Performance Mapping

KPI Summary Cards

Total Visualizations: 6

The dashboard supports dynamic filtering and user interaction for better decision-making.

4. Story

A structured Storyboard was designed to present insights in a logical sequence.

Story Flow:

Overall Sales Overview

Product Placement Effectiveness

Competitor Pricing Analysis

Seasonal Trend Evaluation

Promotion Performance Review

Strategic Recommendations

Total Story Visualizations: 6

The story provides a step-by-step analytical narrative for stakeholders.

5. Creativity (Font and Style)

The dashboard design focuses on professional UI/UX principles.

Clean and minimal layout design.

Consistent font family (Sans-serif professional style).

Balanced color palette for clarity.

Proper alignment and spacing.

High readability and visual hierarchy.

Responsive design structure.

The visual presentation enhances user engagement and improves analytical clarity.
